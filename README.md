# paper-docx-rs

Standalone Rust library and CLI port of [paper-docx](https://github.com/paper-instruments/paper-docx).

The implementation plan and compatibility contracts are in [docs/port-plan.mdx](docs/port-plan.mdx). Start with M0 (contract inventory and Python oracle), then M1 (OPC/XML preservation kernel), progressing toward the M3 safe-editing release. The full roadmap continues through review, compare and composition.

This bootstrap contains planning documents; the Rust implementation follows in an Orca-managed worktree.

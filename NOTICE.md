`docrs-cli`) or the npm package calls Python.

## Font metrics

`crates/docrs/src/layout/font_metrics.bin` holds numeric font
metrics only: units per em, vertical metrics, advance widths and pair
kerning values for a set of code points, generated by
`tools/layout/make_font_metrics.py`. It contains no font software, outlines
or other glyph data. The numbers were measured from fonts installed with
macOS and Microsoft Word for Mac and from Office's downloaded cloud fonts
(as decided for this project on 2026-10-20), and from the Liberation Fonts
2.1.5 (Copyright (c) 2012 Red Hat, Inc., SIL Open Font License 1.1), whose
families LibreOffice-made templates name. The font names in the table are
the families' names as documents refer to them; the fonts' trademarks
belong to their owners.
